We are sharing FreshCart, our C++ mini supermarket billing project at Innovation University.

The project helped us practise loops, switch statements, nested conditions, input validation and separating the interface from the calculation functions. We also built and launched the desktop version on Windows using the Visual Studio C++ tools and VS Code.
