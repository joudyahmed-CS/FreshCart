# خطوات GitHub وLinkedIn والتسليم

## المطلوب حسب ملف الدكتور

مطلوب رابط GitHub عام للكود وREADME، ورابط بوست LinkedIn فيه وصف المشروع وصور أو فيديو ورابط GitHub. ينفع عضو واحد من الفريق يعمل المستودع والبوست ويذكر كل أعضاء الفريق.

## رفع المشروع على GitHub

1. اعمل حساب GitHub وسجّل الدخول، ثم افتح https://github.com/new .
2. اسم المستودع المقترح: FreshCart-CPP . الوصف: C++ mini supermarket billing system with a console version and Qt desktop interface.
3. اختار Public. فعّل Add README عشان المستودع يتفتح بصفحة ملفات، وبعدها Create repository.
4. من المستودع اختار Add file ثم Upload files.
5. فك ضغط حزمة الرفع، وافتح فولدر FreshCart. اسحب محتوياته إلى صفحة الرفع، بحيث README.md وCMakeLists.txt يكونوا في جذر المستودع، ومعاهم src وtests وdocs وباقي ملفات السورس. وافق على استبدال README الافتراضي بالملف المرفق إذا طلب الموقع ذلك.
6. اكتب وصف التعديل Add FreshCart project source and report ثم أكمل حفظ التغييرات. لو الموقع عمل اقتراح تغيير أو فرع جديد، افتح Pull Request وادمجه عشان الملفات تظهر في الفرع الرئيسي.
7. افتح صفحة المستودع وانسخ رابطها وابعتُه هنا. اتأكد إن src/console.cpp وsrc/mainwindow.cpp وREADME.md ظاهرين في الصفحة.

حزمة الرفع جاهزة بدون مجلدات build وout والملفات التنفيذية وملفات Qt الكبيرة. لا ترفع ZIP وحده بدل ملفات السورس؛ المطلوب إن ملفات cpp وREADME تكون متاحة داخل المستودع.

## بوست LinkedIn

افتح حساب LinkedIn لأحد أعضاء الفريق، وانسخ النص من LINKEDIN_POST.md. أضف اسم العضو الثالث ورابط GitHub الحقيقي وصورتين من مجلد screenshots أو فيديو قصير من البرنامج. راجع النص وانشره، وبعدها انسخ رابط البوست.

## قبل التسليم

كمّل بيانات العضو الثالث في Word وTEAM.csv. احفظ التقرير PDF بعد التعديل. جهّز رابط GitHub ورابط LinkedIn وملف التقرير، وراجع شروط الدكتور. للمناقشة، لازم كل عضو يعرف الجزء اللي شارك فيه. نسخة Console مطلوبة، والواجهة إضافة للمشروع.
